# Vibgrate CLI 2026.1027.1

_Released 2026-10-27_

This release of the vg CLI includes important fixes related to dependency classification in SBOM exports and improvements to the drift scanning functionality. Users should review these changes to ensure accurate dependency management and scanning results.

## What changed

### Fixed

- vg sbom export now correctly marks Maven pom.xml dependencies with scope test as development dependencies, and optional true as optional.
- vg scan --drift-worsening without --baseline no longer fails the scan, leaving a measured DriftScore uncompared and skipping the JUnit case.
