# Vibgrate CLI 2026.1020.1

_Released 2026-10-20_

This release of the Vibgrate CLI includes important security updates, new features for advisory scoring, and several performance improvements. Additionally, there are changes to configuration handling and various bug fixes to enhance overall reliability.

## What changed

### New

- `vg scan --fail-on-epss <threshold>` now exits 2 when any advisory's EPSS score meets or exceeds the specified threshold.

### Improved

- `vg sbom export` now correctly marks development and optional dependencies in the SBOM.

### Changed

- When multiple config files set different driftBudget values, vg prints a warning with details about each file.
- `vg review --base` documentation now clarifies how review policies are read from the specified ref.

### Fixed

- `vg report --format html` now correctly displays unmeasured DriftScores as `n/a`.
- `vg serve --review` now properly rejects invalid document IDs and paths.
- `vg fix` now leaves an advisory open if the upgrade fails for any reason and restores the manifest and lockfile.

### Performance

- vg build now reads each project directory only once, optimizing lockfile checks and source discovery.

### Security

- The worker pool now uses tinypool 2.1.2, closing two critical advisories.
