# Vibgrate CLI 2026.1013.1

_Released 2026-10-13_

This release of the Vibgrate CLI includes several improvements to documentation, enhanced handling of lockfiles, and various fixes that improve stability and usability. Notably, it introduces new features for reporting and scanning that enhance the tool's functionality.

## What changed

### Improved

- The CLI docs now explain how to save a drift baseline, gate a build on it, and which exit code that gate uses.
- Lockfile reads keep the dependency graph and SBOM rows when a lockfile adds an optional field this version does not recognize.
- vg scan --vulns now checks transitive dependencies in npm, pnpm, and yarn projects.
- vg build and vg scan do not follow symlinks, preventing potential hangs.
- vg lib docs now name the lockfiles that supply the version label.
- vg report --format html keeps the finding tables first and adds a collapsed footer.
- vg fix docs now explain how to preview a plan before applying it.
- The CLI docs now describe vg serve --http and its related features.

### Changed

- vg report --format html writes a self-contained HTML page from the local scan artifact.
- vg sbom export copies digests a lockfile already recorded onto that one component.

### Fixed

- vg report --format rejects an unknown value with a usage error that names the value and lists the accepted formats.
- vg scan --format sarif now sets partialFingerprints on every result.
- vg evidence release now stops when an SPDX or CycloneDX SBOM is truncated or missing required fields.
- vg build and vg scan print one stderr line when many files fail for the same reason.
- vg scan JSON and SARIF output now use paths relative to the project.
- vg scan reports an unresolved license once for the same package version and source path.
- vg build now resolves workspace packages that share a bare name in a fixed order.
- Reading a ZIP package-version manifest now stops with an error that names the archive path.
- vg scan and vg build stop when a lockfile is truncated or not valid syntax.
- Stopping vg while it writes a graph keeps the previous copy.
- vg scan --summary-out includes the drift budget verdict.
- vg evidence release keeps a CycloneDX or SPDX component that has no package URL when it has a name.

### Security

- Error text that includes a URL now hides credential query parameters when the parameter name is percent-encoded.
