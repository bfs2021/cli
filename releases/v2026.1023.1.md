# Vibgrate CLI 2026.1023.1

_Released 2026-10-23_

This release of Vibgrate CLI includes several important fixes and improvements, particularly around dependency handling and security updates. Users should review the changes related to the `vg sbom export` command and the new GitHub Action feature for enhanced scanning capabilities.

## What changed

### New

- The GitHub Action accepts `fail-on-epss`, allowing users to set a probability threshold for failure.

### Improved

- Documentation now clarifies network usage for `vg ask` steps and evidence handling on air-gapped machines.

### Fixed

- `vg sbom export` correctly marks optional dependencies in Cargo.toml and Poetry files.
- `vg build` now correctly maps directories outside the working directory as their own projects.
- The code map retains Java call and dependency-injection edges for generic types.
- `vg build` follows YAML anchors and aliases in GitHub Actions workflow files.

### Security

- `vg serve` now installs a patched Model Context Protocol library, addressing two high-severity advisories.
